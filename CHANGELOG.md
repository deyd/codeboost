# Change Log

All notable changes to the "codeboost" extension will be documented in this file.

## [1.2] 2025-04-27
- 登録した From / To をコンテクストメニューで呼び出す機能を追加（テキスト選択状態でのみ動作）
- Added a feature to call the registered From/To via the context menu (works only when text is selected).


## [1.1] 2025-04-26
- 登録した Main Marker, Test Marker, Line Marker, Comment Marker をコンテクストメニューで呼び出す機能を追加
- Added functionality to invoke the registered Main Marker, Test Marker, Line Marker, and Comment Marker from the context menu.

## [1.0.2] 2024-09-01
- 検索フォルダ内のサブフォルダが引っかからないよう修正

## [1.0.1]
- マーカーデフォルト値を変更
- 説明アップデート

## [1.0.0]
- Initial release
